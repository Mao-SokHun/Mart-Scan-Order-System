# Mart Scan & Restock Order System 🛒📦
(ប្រព័ន្ធស្កេនទំនិញអស់ស្តុក និងចេញតារាងបញ្ជាទិញសម្រាប់ Mart)

ប្រព័ន្ធនេះត្រូវបានបង្កើតឡើងយ៉ាងពិសេសដើម្បីសម្រួលដល់បុគ្គលិក Mart ក្នុងការដើរឆែកមើលទំនិញដែលអស់ស្តុក ឬជិតអស់ស្តុកនៅលើធ្នើរ ដោយគ្រាន់តែ **Scan Barcode** នោះព័ត៌មានទំនិញនឹងរត់ចូលក្នុង **តារាងទំនិញត្រូវបញ្ជាទិញ (Restock Order Table)** ភ្លាមៗ។

---

## 🌟 លក្ខណៈពិសេសសំខាន់ៗ (Key Features)

1. **ការស្កេនគ្រប់ឧបករណ៍ (Multi-Device Barcode Scanning):**
   * **កាំភ្លើង Scan (Barcode Scanner Gun - USB/Bluetooth):** ប្រព័ន្ធចាប់សញ្ញា Keystroke ស្វ័យប្រវត្តិ។ មិនបាច់ចុច Mouse លើប្រអប់ input ទេ គ្រាន់តែបាញ់ឆ្វេច វានឹងរត់ចូល Table ភ្លាម!
   * **កាមេរ៉ាទូរស័ព្ទ (Smartphone Camera Scanner):** បុគ្គលិកគ្រាន់តែបើក Browser លើទូរស័ព្ទដៃ (iOS Safari ឬ Android Chrome) ចូលទៅកាន់តំណភ្ជាប់ Network គឺអាចបើកកាមេរ៉ាស្កេន Barcode បានយ៉ាងរហ័ស ព្រមទាំងមានភ្លើងពិល (Flash/Torch) សម្រាប់ទីតាំងងងឹត។
   * **បញ្ចូលលេខ Barcode ដោយផ្ទាល់:** អាចវាយលេខ និងចុច Enter ដើម្បីបញ្ចូលទំនិញ។

2. **តារាងទំនិញត្រូវបញ្ជាទិញ (Restock Order Table):**
   * បង្ហាញព័ត៌មានលម្អិត៖ រូបភាព, ឈ្មោះទំនិញ (អង់គ្លេស + ខ្មែរ), Barcode, ស្តុកបច្ចុប្បន្ន (ប៊ូតុងក្រហម "អស់ស្តុក"), អ្នកផ្គត់ផ្គង់ (Supplier), តម្លៃដើម, និងសរុបទឹកប្រាក់។
   * បើស្កេនទំនិញដដែលម្តងទៀត វានឹងបូកចំនួនថែម (+1) ស្វ័យប្រវត្តិ។
   * មានប៊ូតុង `+` និង `-` ដើម្បីកែប្រែចំនួនដែលត្រូវទិញបន្ថែម។
   * ច្រោះទំនិញតាមអ្នកផ្គត់ផ្គង់ (Filter by Supplier)។

3. **ការនាំចេញទិន្នន័យ និងការបញ្ជាទិញ (Export & Ordering):**
   * **Export ជា Excel (.xlsx):** ទាញយកតារាងជា Excel ភ្លាមៗ។
   * **ផ្ញើតាម Telegram / WhatsApp:** ចម្លង Text សង្ខេបបញ្ជីទំនិញត្រូវទិញ សម្រាប់ផ្ញើទៅ Supplier តាម Telegram តែមួយ Click។
   * **បោះពុម្ពសន្លឹកបញ្ជាទិញ (Print Purchase Order):** ចេញទម្រង់ PO ផ្លូវការសម្រាប់ Print លើក្រដាស A4 ឬ Save ជា PDF ដែលមានកន្លែងចុះហត្ថលេខាបុគ្គលិក និងអ្នកគ្រប់គ្រង។

4. **ប្រព័ន្ធចុះឈ្មោះទំនិញថ្មី (On-The-Fly Product Registration):**
   * បើស្កេនចំ Barcode ណាដែលមិនទាន់មានក្នុងប្រព័ន្ធ វានឹងលោតផ្ទាំងឱ្យចុះឈ្មោះទំនិញនោះភ្លាមៗ និង Add ចូលតារាងទិញតែម្តង។

5. **សំឡេង និងញ័រ (Beep & Haptic Feedback):**
   * មានសំឡេង "ប៊ីប" ពីរោះបែបម៉ាស៊ីន Cashier ពេលស្កេនត្រូវ និងសំឡេង Buzz ពេលមិនស្គាល់ Barcode។
